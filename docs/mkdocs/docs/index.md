# Operon

**Fast and scalable genetic programming for symbolic regression.**

Operon is a modern C++ framework for building, evaluating, and evolving symbolic-expression trees. The guides describe the model, execution, evaluation, search, and shape-certification boundaries used by both the library and command-line tools.
